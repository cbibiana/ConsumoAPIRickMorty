# Consumo API Rick and Morty - Windows Forms C#

Aplicacion de escritorio en Windows Forms que consume la API publica de Rick and Morty para mostrar informacion de personajes.

## Tecnologias

- C# .NET
- Windows Forms
- HttpClient (Consumo de API REST)
- Rick and Morty API (https://rickandmortyapi.com/)

## Funcionalidades

- Consumo de API REST externa
- Deserializacion de JSON a objetos C#
- Visualizacion de datos en DataGridView
- Manejo de peticiones HTTP asincronas

## API utilizada

- URL Base: https://rickandmortyapi.com/api
- Endpoint: /character

## Como ejecutar

1. Clonar el repositorio
2. Abrir la solucion en Visual Studio
3. Ejecutar con F5
